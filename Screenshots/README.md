# Screenshots

This folder contains UI screenshots demonstrating the Advanced Password Generator application's features and interface.

## Contents

- **example batch generation.png**: Batch password generation results showing 5 strong passwords with strength indicators
- **example generated password.png**: Single password generation view with a generated password, copy button, and strength indicator showing "Strong"
- **opening page pt 1.png**: Advanced Password Generator settings panel displaying:
  - Password length configuration (12 characters default)
  - Character type options (lowercase, uppercase, numbers, symbols)
  - Security options (complexity enforcement, ambiguous character avoidance, no repeating characters)
  - Customization fields (exclude/must include specific characters)
- **opening page pt 2.png**: Bottom section showing the batch generation feature with options to generate multiple passwords at once (5 password batch example)

These screenshots illustrate the application's password generation capabilities, customization options, and security features.
